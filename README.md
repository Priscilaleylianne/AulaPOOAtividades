# UC:Programação Orientada a Objetos (POO)

Este repositório contém os materiais, exercícios e projetos desenvolvidos no contexto de estudos e práticas sobre **Programação Orientada a Objetos (POO)**, utilizando as linguagens **Java**, **C#** ou **PHP**, de acordo com as orientações pedagógicas do curso.

## Objetivos

Desenvolver competências técnicas e socioemocionais aplicadas à construção de soluções de software com foco em **orientação a objetos**, utilizando boas práticas de desenvolvimento e trabalho colaborativo.

---

## Competências Técnicas e Socioemocionais (Conforme PPC)

- Aplicar conceitos de Programação Orientada a Objetos (POO), implementando **classes e objetos**.
- Reutilizar código através de **herança** e **polimorfismo**.
- Escrever **códigos limpos, modulares e eficientes**.
- Gerenciar o tempo no desenvolvimento de software.
- Desenvolver **habilidades de colaboração** e comunicação assertiva em equipe.

---

## Habilidades Desenvolvidas

- Reconhecimento e implementação de **classes e objetos** em exercícios práticos.
- Aplicação de **herança, polimorfismo e encapsulamento**.
- Programação orientada a objetos em **Java**, **C#** ou **PHP**.
- Desenvolvimento de projetos **funcionais e eficientes**.
- Comunicação clara de ideias durante o desenvolvimento de software.
- Uso do **Git** para versionamento e colaboração.
- Desenvolvimento de **projetos práticos e desafios de programação**.

---

## Conteúdos Abordados

| Conteúdo                                  | Descrição                                                                         |
| ----------------------------------------- | -------------------------------------------------------------------------------- |
| **Classes e Objetos**                     | Definição, criação, utilização e relacionamentos entre objetos                   |
| **Herança, Polimorfismo e Encapsulamento** | Implementação de hierarquias, métodos sobrecarregados e proteção de atributos    |
| **POO em Java / C# / PHP**                | Sintaxe, estrutura de dados e tratamento de informações                         |
| **Criação de Soluções de Software**       | Planejamento, codificação e documentação de projetos                             |
| **Boas Práticas de Programação**          | Código limpo, legível, organizado e seguindo convenções                         |
| **Exploração de Novas Funcionalidades**   | Pesquisa, implementação e avaliação de novas técnicas e ferramentas             |
